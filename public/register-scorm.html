Register Existing SCORM Package

This utility helps you register your existing SCORM content with a course so it shows up in the interactive menu.

How it works:

  1. Fill out the form below with the details of your SCORM package
  2. The utility will create a record in the database for your SCORM module
  3. It will associate the module with the selected course
  4. Your existing SCORM content in /public/Scorm/1/training.htm will be used directly
  5. The module will appear in the "Interactive" tab of the selected course
